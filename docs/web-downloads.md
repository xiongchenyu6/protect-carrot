# 浏览器资源与离线游玩

启动页默认中文，进入游戏前可切换语言；同一份 `protect_carrot_lang` 设置供游戏使用。手机通过启动页的安装引导添加到桌面。实际浏览器是否支持 WebGPU 仍由设备决定，安装 PWA 不会补足缺失的 GPU 能力。

首次启动只保存引擎、菜单图像和公共界面。点击战役关卡或无尽模式时，显示战斗包的实际下载量；玩家可以返回菜单。下载、SHA256 校验和战斗特效解码完成后才进入关卡，没有倒计时强行放行。战役和无尽模式使用同一份战斗包，不人为复制 100 份关卡资源。

菜单的「设置 → 下载与离线游玩」可以预先下载全部内容、查看已保存大小、移除额外资源。移除不触碰进度，正在使用的战斗包受保护。浏览器主动清理站点存储后仍需重新下载；安装不保证永久保存。

每次发布生成文件清单，资源按 SHA256 内容地址保存。重开游戏复用已校验资源；新版本先提示实际需要下载的差量，由玩家确认，准备完整后切换。下载失败或校验失败不替换旧版本。发布时保留上一版内容地址，旧会话不会因为路径覆盖混入新文件。

编译输入指纹覆盖 Rust 源码、依赖锁、构建参数文件及嵌入资源。仅修改网页或独立美术资源时，构建脚本核验线上引擎的大小和 SHA256 后复用，包括 wasm-bindgen 的 `snippets/`。修改 Rust 或嵌入数据仍需重新下载变化的完整 WASM 文件；本方案是文件级差量，不是二进制分块补丁。

发布只带运行时实际引用的 PixelFX 动画。背景音乐由 WAV 转成 Ogg Vorbis，原始 WAV 保留作源素材，不进入网页包。字库已嵌入引擎，不再重复发布外部字库。

验证：`python3 -m unittest discover -s tools -p 'test_*.py'`、`node --test tests/web_audio_unlock.mjs`，以及 `tools/test_pwa_cache.cjs`、`tools/test_pwa_demand.cjs`、`tools/test_launcher.cjs`。浏览器测试需要 Playwright 与 Chromium；真实 WebGPU 开局验证记录在 `docs/verification/`。
