# 战斗手感优化

## 目标与范围

落实已确认的打击链：短蓄力、快速释放、接触停顿、受力与清晰收招。
包括九种武器的差异化节奏、基于相位的姿势曲线、局部命中停顿、定向受力、
普通／重击／强化／终极技能／首领终结的视觉与声音分级，以及高频反馈预算。

不新增伤害、随机暴击、装备或经济规则，不等待付费素材，不修改现有用户改动。
当前没有随机暴击系统；强化反馈对应真实的元素弱点或强化攻击，不能虚构暴击数字。
命中停顿作用于参与者的视觉姿势，不冻结 UI、移动输入、寻路或全场模拟。

## 可观察行为

- 匕首、弓弩快速起手收招；剑盾中等；锤和召唤更有预备感。终结技预备更明确。
- 蓄力缓入，释放快速且方向明确，收招平滑归位，不再匀速扫过整张帧图。
- 有效重击落地才触发局部停顿、挤压和定向回弹；挥空不触发命中反馈。
- 普通塔弹不震屏、不全场停顿；伤害与碰撞结果不受视觉位移影响。
- 群攻不叠加无限震屏、碎片或停顿；新一击不能持续锁住受击姿势。
- 终极技能和首领终结有独立预算，不被普通强化命中占满；同帧同位置、同标签的
  伤害数字合并为实际总量，不改变伤害结算。
- 暂停保留当前表现，恢复后连续；倍速不把短停顿变成长时间卡顿。

## 验收

- `cargo fmt --check`、`cargo check --all-targets`。
- `cargo test --lib`、`cargo test --test hero_passives` 与新增反馈测试：
  武器节奏差异、相位端点、真实命中／挥空、局部停顿、反馈限流、暂停恢复、
  视觉位移不污染仿真位置、相同命中次数在 30/60 FPS 下产生一致结果。
- 桌面与移动端捕获蓄力、释放、接触、收招连续帧；覆盖轻击、重击、强化、
  首领终结及密集塔群。不能仅凭单张截图或事件存在宣称手感完成。

## 风险

局部效果和现有精灵动画／后坐力可能重复写变换，需要明确清理和渲染顺序。
节奏变化不能破坏技能取消、命中时机、冷却和召唤容量等现有回归约束。
