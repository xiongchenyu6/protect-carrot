# 《保卫萝卜》Bevy 版玩法攻略

这份文档用于对外发布攻略，也作为项目内的核心玩法说明。当前版本的构筑核心是：

> 种族决定底色，武器决定打法，英雄装备和防御塔宝石补强方向，每波三选一天赋把整局路线滚起来。

传统“职业”概念已经不作为核心系统使用。玩家在战前选择的是种族与武器，战斗中也围绕武器、装备、塔阵、宝石、天赋来成型。

## 一、先理解胜利循环

每一关的目标很直接：守住萝卜，不让怪物从入口冲到终点。真正决定胜负的是四个循环：

1. 开局用低价塔守住关键拐角，不要第一时间贪终局塔。
2. 用英雄补线、拉怪、处理漏怪，英雄不是菜单里的头像，而是战场单位。
3. 每波结束后从种族、武器、公共池中三选一天赋，围绕当前打法继续强化。
4. 把掉落的装备和宝石投入到正在成型的路线，而不是平均分散。

通关不是“塔越贵越好”，而是“敌人弱点、地图路线、英雄定位、塔阵功能”能不能对上。

## 二、核心系统详解

这一章按系统解释游戏怎么运转。玩家攻略可以直接摘用，开发时也应该以这里的边界为准：英雄系统、防御塔系统、宝石系统和菜单图鉴系统要各司其职，不能重新混成一个面板。

### 1. 关卡与波次系统

关卡由路径、建造格、入口、萝卜终点、天气主题、敌人池和 Boss 波组成。玩家不是在空白棋盘上堆塔，而是在一条确定路线周围规划火力窗口。

每一波敌人会沿路径推进，波次越高，敌人生命、数量、特殊词条和 Boss 压力越强。Boss 通常出现在关键波次和最终波，后期关卡会更频繁地给玩家施加首领技能、精英突变、攻城怪和迷雾压力。

玩家要做的决策：

1. 开局先看路径拐角和长直线，决定第一批塔的位置。
2. 中期根据波次情报补隐形、飞行、重甲、自爆等针对手段。
3. Boss 波前把金币投入主输出、减速和英雄站位，而不是继续铺低级塔。
4. 不同关卡的天气和光照会影响视觉判断，不能只按第一关习惯建塔。

设计重点：关卡不是背景图，而是构筑约束。路径越复杂，控制塔越强；路径越短，爆发塔和英雄补线越重要；迷雾越重，光源和侦测越值钱。

### 2. 难度与部署系统

战前部署页面负责让玩家理解本关节奏：目标波数、初始金币、生命、出怪基础数量、推荐元素和可能出现的首领威胁。

难度影响容错率。普通难度适合学习系统，困难难度会更考验经济效率、塔位规划和英雄操作。玩家如果第一次进入一张新地图，不建议直接用高风险武器和极限经济路线。

部署阶段的核心不是“选最强”，而是“选最适合这张地图的开局方案”：

- 路线很长：可以贪经济和成长。
- 路线很短：必须优先稳定输出和减速。
- 有水域、峡谷、狭窄通道：范围塔、风塔、雷塔、导弹塔收益更高。
- 预计有隐形或迷雾：侦测塔、哨戒弩、光源要提前规划。

### 3. 种族系统

种族决定英雄基础属性倾向，但不再绑定传统职业。当前核心种族是人类、精灵、兽人。

人类是标准全能种族，伤害、生命、攻速没有明显短板。它适合新手，也适合还没摸清敌人池的关卡。人类的价值在于不挑武器，不容易因为一项短板导致整局崩盘。

精灵强调射程、攻速和移动，适合远程武器、探路、补线和经济打法。精灵的问题是生命容错较低，不能长期站在自爆怪、冲锋怪或 Boss 面前硬扛。

兽人强调生命和伤害，适合近战武器、卡线、抗压和正面打 Boss。兽人的代价是射程和机动压力更明显，玩家需要更早规划英雄站位。

种族选择会进入每波三选一天赋池。也就是说，种族不是开局一次性属性，而是整局构筑路线的源头。

### 4. 武器系统

武器取代传统职业，决定英雄的攻击方式、技能、天赋路线、纸娃娃外观和战场定位。玩家选择的是“这局英雄怎么打”，不是选择一个固定职业身份。

近战武器适合守线和贴身处理漏怪，但需要控制自爆怪和 Boss 技能风险。远程武器适合持续输出和安全收割，但需要塔阵帮忙拖住敌人。辅助武器不一定面板伤害最高，但能显著改变塔阵效率。

武器理解方式：

- 战旗长剑：英雄自己站得住，适合补线和独立守关。
- 星火法杖：用火球和范围伤害清怪群，怕高抗性和分散敌人。
- 猎影长弓：用击杀金币滚雪球，前期越早抢到人头越强。
- 誓约盾锤：英雄站在塔阵旁边，提升整体防线效率。
- 雷暴法器：用减速和连锁控制怪群，给高伤塔争取输出时间。
- 哨戒弩：解决射程、反隐和远程压制问题，是功能型武器。
- 夜刃匕首：靠绕后和背击打 Boss，上限高但需要操作。
- 召唤法杖：召唤移动神话眷属，削弱敌人并强化召唤体系。
- 工匠战锤：近战锤击加攻速光环，主动组装临时守卫，适合围绕核心塔阵站场。

战斗中如果开放武器切换，切换的也应该是武器路线，而不是恢复职业系统。技能、纸娃娃和天赋描述都应跟随当前武器。

### 5. 英雄控制系统

英雄是一个可移动战斗单位，不是被动头像。玩家点击战场上的英雄应选中英雄，右键地图应移动英雄。英雄菜单、纸娃娃、背包和图鉴入口不能抢走战场点击。

英雄的主要职责有四个：

1. 补漏：敌人越过塔阵后，英雄移动到后段截杀。
2. 卡线：近战英雄站在关键格附近拖住怪物。
3. 拉扯：远程或脆皮英雄通过移动保持安全距离。
4. 触发构筑：光环、治疗、减速、赏金、背击等武器能力需要正确站位。

英雄不要一直站在地图中央。长线图要让英雄在薄弱路段巡逻，短线图要让英雄靠近萝卜或关键拐角，迷雾图要让英雄和光源一起推进视野。

### 6. 英雄成长、天赋点与终极能力

英雄通过战斗获得经验并升级。升级后获得天赋点，用来强化当前武器的天赋。高等级会解锁武器终极能力，让英雄从“补线单位”变成构筑核心。

成长系统的设计目的不是让玩家无脑点满所有东西，而是让玩家在当前武器内选择方向：

- 近战武器优先生存、伤害、护甲、回血。
- 远程武器优先射程、攻速、技能伤害。
- 辅助武器优先光环、控制、治疗、召唤收益。

如果玩家频繁切换武器，就要接受成长分散的代价；如果专精一个武器，就能更早进入强势阶段。

### 7. 纸娃娃与英雄装备系统

纸娃娃系统负责把种族、武器和装备表现到英雄外观上。它不是装饰页，而是玩家确认“我现在这套构筑是什么”的核心反馈。

英雄装备建议拆成四个决策位：

1. 武器：决定攻击方式、技能和主构筑路线。
2. 战衣：决定生存、防御和身体外观。
3. 护符：决定技能、续航、功能强化。
4. 圣物：决定终局特效、特殊机制和高阶辨识度。

背包只显示已获得物品。未获得装备可以在图鉴中以锁定或剪影方式提示，但不应该在战斗背包里完整铺开，否则玩家会误以为都可使用。

纸娃娃预览必须与战场角色一致：玩家在纸娃娃页看到的人类、精灵、兽人外观，应该和战场英雄保持同一套基础形象和装备变化。

### 8. 防御塔建造系统

防御塔是主防线。玩家先在右侧选择塔，再点击可建造格放置。建造位置比塔本身更重要，同一座塔放在拐角和直线末端，实际输出可能差很多。

建塔优先级：

1. 第一批塔放在能覆盖最长路径的位置。
2. 第二批塔补控制，尤其是冰塔、风塔、雷塔。
3. 第三批塔补功能，解决隐形、飞行、重甲、自爆。
4. 局势稳定后再投资终局塔。

防御塔不应该被当成纯数值按钮。每类塔要有明确职责：单体、范围、减速、侦测、破甲、召唤、攻城、终局输出。

### 9. 防御塔升级、修理与目标系统

选中防御塔后，玩家应进入塔专属面板：升级、修理、目标优先级、宝石镶嵌、出售、重置等操作都在这里完成。

升级提升塔的基础输出、生命、射程或特殊能力。关键塔升级后体积和光照范围也应更强，让玩家从视觉上感到它变成了防线核心。

修理用于应对攻城怪、爬墙怪、MOSS 和 Boss 技能。塔被攻击时不能只靠生命条提示，玩家需要通过危险连线、火花、文字和音效知道哪座塔正在被拆。

目标优先级用于处理复杂波次：

- 最近：适合普通防线。
- 最前：适合防漏。
- 最强：适合打精英和坦克。
- 最弱：适合收割触发经济。
- Boss / 攻城优先：适合后期威胁波。

### 10. 宝石系统

宝石是防御塔和英雄装备之间的共享构筑资源。它的作用不是单纯加数值，而是让玩家决定“这局主力是谁”。

宝石系统应遵守三个原则：

1. 镶嵌入口跟随对象。选中塔时镶嵌塔宝石；打开英雄背包时处理英雄装备宝石。
2. 已获得才显示。背包展示拥有的宝石，图鉴展示发现过或可预览的宝石。
3. 强化要集中。主输出塔、核心英雄装备、控制塔各吃不同宝石，不要平均分。

常见宝石方向：

- 伤害宝石：给光棱塔、要塞炮、导弹塔、主输出英雄。
- 攻速宝石：给高基础伤害塔、工匠战锤光环体系。
- 射程宝石：给狙击、导弹、哨戒弩体系和迷雾图核心塔。
- 控制宝石：给冰塔、风塔、雷塔，让怪物停留在火力区。
- 元素宝石：根据敌人弱点补火焰、冰霜、雷风、圣光、暗影等路线。

### 11. 每波三选一天赋系统

每波结束后的三选一是肉鸽构筑核心。它让同一张地图每次都能打出不同路线。

三类天赋池：

- 种族池：强化人类、精灵、兽人的种族特色。
- 武器池：强化当前武器，推动英雄成为主力或关键辅助。
- 公共池：强化塔阵、宝石、金币、全局收益。

选择逻辑：

- 前期缺钱，拿金币和成长。
- 当前漏怪，拿控制、攻速、射程或英雄伤害。
- Boss 打不动，拿单体爆发、破甲、背击和终局塔强化。
- 塔阵已经稳定，拿防线超频、宝石共振等全塔收益。
- 英雄已经成型，继续拿武器精通、武器节奏、武器秘技。

三选一最忌讳什么都拿一点。正确做法是让路线越来越窄：这局到底是英雄主 C、光棱塔主 C、召唤拖线、远程经济，还是控制磨死。

### 12. 经济、连杀与奖励系统

金币来自初始资金、击杀、波次利息、完美防守、天赋奖励、猎影长弓赏金和部分技能收益。经济系统的重点是节奏，而不是总量。

前期金币要买稳定，中期金币要补短板，后期金币要集中砸核心。最危险的用法是前期裸出高价塔，导致控制不足；或者后期继续铺低级塔，导致 Boss 输出不够。

连杀和完美防守会给额外奖励。玩家如果能让敌人在同一火力区密集死亡，就能把炮塔、火塔、冰塔、雷塔、导弹塔的收益放大。

掉落系统负责给玩家持续成长。普通怪、精英、Boss 都可能给装备或宝石；Boss 掉落应该更稳定、更有期待感。战斗中掉落要有图标、稀有度、音效和浮字，否则玩家很难意识到构筑资源正在进入背包。

### 13. 主动技能系统

主动技能是给玩家处理危机的短期手段，不应该替代塔阵规划。

常用理解：

- 陨石：清理局部高压，适合怪群进入拐角或 Boss 召唤杂兵时使用。
- 全场冻结：争取时间，适合漏怪、冲锋怪、自爆怪贴近核心塔阵前使用。
- 金币技能：牺牲短期技能窗口换经济，适合局势稳定时滚雪球。

主动技能最怕乱放。技能应该用于改变局势：救漏、保塔、控 Boss、抢经济，而不是冷却好了就按。

### 14. 元素、抗性与弱点系统

敌人和塔都有元素关系。火焰、冰霜、雷风、圣光、暗影、物理、秘法等伤害会因为敌人抗性不同而产生差异。

玩家要看波次情报里的推荐元素。如果提示敌人火焰弱，就优先考虑火塔、星火法杖、燃烧类宝石；如果敌人物理抗性高，就不要继续只堆箭塔和普通炮塔。

元素系统的价值是让玩家换打法，而不是背表。只要记住：

- 弱点元素负责打穿关键敌人。
- 控制元素负责延长输出时间。
- 抗性提示意味着当前主输出可能会打折。

### 15. 敌人、精英与怪物图鉴系统

怪物不是只有血量和速度。当前敌人包括普通、快速、坦克、飞行、隐形、再生、重甲、集群、护盾、分裂、治疗、冲锋、爬墙、静默、远射、自爆、MOSS 等行为。

精英敌人会携带突变词条，例如更快、更硬、孵化、血祭、攻城等。突变会改变优先级：一个普通怪带攻城词条后，威胁可能比高血怪还高。

图鉴系统负责把玩家遇到过、击杀过、发现过的怪物整理出来。它的作用不是收藏展示而已，还应该告诉玩家：

- 这只怪是什么行为。
- 它怕什么元素。
- 它抵抗什么伤害。
- 它在什么关卡或波次容易出现。
- 它需要什么塔或武器处理。

第一次遭遇新威胁时，战场上应有明确提示，让玩家知道不是“突然漏怪”，而是出现了新的机制怪。

### 16. Boss 与首领技能系统

Boss 是每关节奏的压力测试。它不应该只是血更多的怪，而是会强迫玩家检查自己的构筑短板。

Boss 常见压力：

- 高生命和护盾，要求单体爆发。
- 特殊技能，要求玩家看预警圈和技能名。
- 攻城或吞塔，要求修理和保护关键塔。
- 狂怒阶段，要求最后一段集火和控制。
- 召唤或分裂，要求范围清怪能力。

打 Boss 前要做四件事：

1. 确保有减速或控制。
2. 确保有单体输出。
3. 确保关键塔能被修理或保护。
4. 让英雄站在能输出但不白吃技能的位置。

### 17. 召唤与死灵系统

召唤塔、死灵塔、召唤法杖和部分技能会产生友方单位。召唤物的定位是拖线、吸收伤害、补输出，而不是替代整个塔阵。

召唤系统要注意三点：

- 召唤物应围绕召唤范围和目标行动，不能无限跑出职责区。
- 一级召唤上限要清晰，避免玩家误以为塔失控。
- 召唤物要有朝向、攻击动作和受击反馈，否则玩家会感觉它们在发呆。

召唤路线适合持久战、治疗光环、减速阵地和关口拖延，但遇到强范围 Boss 或自爆怪时要特别小心。

### 18. 战争迷雾、光照与天气系统

从第二关开始，战争迷雾逐步进入战斗。它的核心不是把画面变暗，而是让“视野”和“光源”成为塔防决策。

有效光源包括地图火把、火焰塔、部分高级塔、英雄武器、投掷物、技能和萝卜周围的安全光。默认环境光应偏夜晚，地图不应该全亮；玩家应该能看出哪里被火把照亮，哪里仍处在危险暗区。

迷雾图的打法：

- 入口附近要有光源，否则怪物出现太晚。
- 关键拐角要有光源，否则塔阵反应慢。
- 火焰塔不仅是输出，也是战术照明。
- 英雄可临时探视野，但不能替代固定光源。
- 只有被照亮或侦测到的敌人才应该稳定进入玩家判断。

天气和地图主题应该改变视觉和战术感受：沙漠可以更热、更亮但有尘雾；雪地图可以冷色和低对比；沼泽可以有绿雾和遮挡；火山可以有高亮熔岩与危险阴影。

### 19. 图鉴、军械库与长期进度系统

主菜单不只是开始游戏。它应该承载长期成长和信息查询：

- 怪物图鉴：查看已发现怪物、弱点、抗性、技能和击杀记录。
- 防御塔图鉴：查看 19 种塔的定位、费用、元素、升级方向和克制目标。
- 英雄装备图鉴：查看已发现装备、适配武器、纸娃娃外观和掉落来源。
- 宝石图鉴：查看已发现宝石、适合镶嵌对象和构筑方向。
- 战役档案：查看 20 个关卡的路线、首领预告、推荐元素和历史评级。

战斗背包只放“当前可用资源”，图鉴放“收集与说明”。这两个入口不能混在一起，否则玩家会在战斗中被大量说明文字和未获得物品干扰。

### 20. UI 入口与交互边界

当前 UI 应按对象分离：

- 主战场：移动英雄、建塔、选塔、释放技能。
- 英雄菜单：查看状态、纸娃娃、装备、武器和背包。
- 物品菜单：查看当前拥有的装备、宝石和消耗资源。
- 塔面板：只在选中防御塔时出现，处理升级、修理、目标、宝石、出售。
- 图鉴页面：首页或大厅入口，负责长期信息查询。

Esc 应关闭当前打开的临时页面，例如宝石袋、英雄状态页、背包弹窗。战场点击不应误打开纸娃娃；点击应用或确认按钮也不应吞掉之后的棋盘输入。

交互设计的目标是让玩家永远知道自己正在操作什么对象：英雄、塔、背包、图鉴、还是战场。

## 三、战前选择：种族 + 武器

战前页面只需要玩家做两类选择：种族和武器。种族提供基础属性倾向，武器提供战斗定位、技能、天赋路线和纸娃娃外观。

### 种族定位

| 种族 | 定位 | 适合玩家 |
|------|------|----------|
| 人类 | 全能型，生命、伤害、攻速都有加成 | 新手首通、未知地图、稳健构筑 |
| 精灵 | 射程、攻速、移速更高，生命较低 | 远程武器、打钱发育、走位操作 |
| 兽人 | 伤害和生命更高，射程、攻速、移速有代价 | 近战武器、扛线、正面压制 |

新手建议先用人类。它不是上限最高的种族，但容错率最高，适合摸清敌人、地图和塔阵节奏。

### 武器定位

| 武器 | 定位 | 核心打法 |
|------|------|----------|
| 战旗长剑 | 近战 · 单刷守关 | 持续回血，适合英雄独立卡线 |
| 星火法杖 | 远程 · 范围歼灭 | 火球和范围爆发，适合清群 |
| 猎影长弓 | 远程 · 打钱发育 | 击杀获得额外金币，越早成型越赚 |
| 誓约盾锤 | 近战 · 扛线增伤 | 自身抗压，并强化附近防御塔 |
| 雷暴法器 | 辅助 · 群体减速 | 控场和雷链，拖住密集怪群 |
| 哨戒弩 | 辅助 · 射程增幅 · 反隐形 | 扩大塔阵射程，处理隐形威胁 |
| 夜刃匕首 | 近战 · 背击打 Boss | 绕后爆发，适合熟练玩家打首领 |
| 召唤法杖 | 远程 · 神话召唤 · 裂界削弱 | 召唤移动神话眷属，联动召唤塔和死灵塔 |
| 工匠战锤 | 近战 · 临时守卫 · 攻速超频 | 近战守线，组装临时守卫并提升周围塔攻速 |

推荐首通组合：

- 人类 + 战旗长剑：稳，英雄能独立处理漏怪。
- 人类 + 誓约盾锤：适合传统塔防玩家，英雄站在塔阵旁边提升防线。
- 精灵 + 猎影长弓：金币成长快，但需要更主动地补线和选点。
- 兽人 + 工匠战锤：近战强势，适合围绕核心塔阵打正面阵地战。

## 四、战斗操作重点

| 操作 | 目的 |
|------|------|
| 左键点击英雄 | 选中英雄 |
| 右键点击地图 | 命令英雄移动 |
| 左键点击塔 | 选中防御塔，打开升级、修理、目标、宝石等塔相关操作 |
| 左键点击建造按钮，再点可建造格 | 建造防御塔 |
| Esc / 右键空地 | 关闭宝石袋、英雄状态页或取消当前选择 |
| Space | 开始下一波 |
| Q / W / E | 释放主动技能 |

战斗中的一个重要原则是：点击战场英雄应该选中英雄，右键移动；英雄纸娃娃和装备页面属于独立界面，不应该抢走战场点击。

## 五、防御塔不是只比伤害

防御塔可以粗略分为输出、控制、功能、召唤、终局五类。新手最常见错误是只看攻击力，不补控制和功能塔。

### 前期基础塔

- 箭塔：便宜、稳定，适合补单体输出。
- 炮塔：范围伤害，适合路径拐角和怪群入口。
- 冰塔：减速核心，能让所有输出塔多打几轮。

前期推荐组合是箭塔 + 炮塔 + 冰塔。只要地图有拐角，优先围绕拐角铺塔。

### 功能塔

- 侦测塔：对抗隐形怪的关键。没有侦测，再高伤害也可能打不到。
- 风塔、雷塔：负责控制、连锁、处理高速单位。
- 圣光塔、暗影塔、毒塔、火塔：根据敌人抗性和弱点选择。

### 召唤与防线塔

- 召唤塔：召唤单位拦截敌人，适合拖线和保护薄弱路段。
- 死灵塔：偏消耗和亡灵体系，适合长线战斗。
- 要塞炮：高压路段和 Boss 波的重火力。

召唤塔和死灵塔不是“无脑主输出”，它们更像防线延长器。最好配合治疗、减速、光环和范围塔。

### 终局塔

- 光棱塔：高价终局塔，应该承担后期主输出职责。
- 导弹塔：适合处理飞行、远距离和多点压力。
- 要塞炮：适合守关键路口和高血量目标。

终局塔必须配合升级、宝石和天赋。单独裸放一座贵塔，往往不如一组便宜塔加控制稳定。

## 六、宝石系统：塔和英雄装备共用构筑资源

当前设计中，防御塔装备逐步转为宝石系统。宝石可以镶嵌防御塔，也可以服务英雄装备构筑。

宝石选择优先级：

1. 已经成型的主输出塔优先吃伤害、攻速、射程宝石。
2. 控制塔优先吃射程、冷却、持续时间相关收益。
3. 英雄如果是主力输出，优先强化对应武器的装备和宝石。
4. 不要把宝石平均分给每座塔，平均分配会让整局没有爆点。

防御塔的升级、修理、目标切换和宝石镶嵌都应该通过选中塔触发。英雄装备、纸娃娃和背包则通过英雄菜单处理，避免塔系统和英雄系统混在一起。

## 七、每波三选一天赋：肉鸽构筑的核心

每波结束后，系统会提供三类天赋来源：

- 种族池：强化当前种族特色。
- 武器池：强化当前武器打法。
- 公共池：强化塔阵、宝石、金币等通用路线。

### 什么时候选什么

| 当前问题 | 优先选择 |
|----------|----------|
| 前期缺钱 | 金币、补给、分红、猎影长弓相关收益 |
| 漏怪 | 减速、攻速、射程、英雄伤害 |
| Boss 打不动 | 单体爆发、破甲、背击、光棱塔强化 |
| 怪群太密 | 范围伤害、火焰、炮塔、法杖、雷链 |
| 塔阵已经稳定 | 防线超频、宝石共振、全塔增益 |
| 英雄是主力 | 武器精通、武器节奏、武器秘技 |

不要看到稀有天赋就点。三选一真正的价值在于让路线变窄、变强、变明确。

## 八、敌人克制速查

| 敌人类型 | 处理方法 |
|----------|----------|
| 普通怪 | 正常塔阵即可，注意不要让经济断档 |
| 快速怪 | 冰塔、风塔、雷暴法器，先减速再输出 |
| 坦克怪 / 重甲怪 | 魔法、暗影、光棱、破甲效果 |
| 飞行怪 | 狙击塔、雷塔、导弹塔、远程英雄 |
| 隐形怪 | 侦测塔、哨戒弩，越早补越安全 |
| 护盾怪 | 多段伤害、持续伤害、破盾后爆发 |
| 再生怪 / 治疗怪 | 集火击杀，不要让它们把战线拖长 |
| 分裂怪 / 集群怪 | 炮塔、火塔、冰霜新星、导弹塔 |
| 冲锋怪 | 提前减速，别让它一口气越过火力区 |
| 爬墙怪 / 攻城怪 | 保护关键塔，及时修理，必要时英雄补位 |
| 静默怪 | 分散核心塔，避免整片输出被停火 |
| 远射怪 | 用英雄或远程塔尽快点杀 |
| 自爆怪 | 主动靠近塔或英雄后爆炸，击杀不会触发自爆；要远距离减速和集火 |
| Boss | 减速、单体爆发、破甲、英雄技能都要准备 |

自爆怪尤其要注意：它不是死亡爆炸，而是主动靠近后触发爆炸。正确做法是别让它贴到核心塔阵和英雄。

## 九、战争迷雾、光源和地图理解

从第二关开始，战争迷雾会逐步成为地图机制。只有被光照亮或视野覆盖的敌人，才更容易被发现和稳定攻击。

地图上的火把、火焰塔、部分防御塔、英雄武器、投掷物和技能特效都可以成为光源。夜间环境下，默认地图不应该全亮，而应该围绕火把、塔和英雄形成亮区。

有战争迷雾时要改变建塔思路：

- 不要所有塔都堆在萝卜旁边。
- 入口、拐角、长直线起点都要有视野。
- 火把和火焰塔不只是装饰，它们也是战术信息来源。
- 英雄可以临时探路，但不要让英雄孤身站在自爆怪和 Boss 面前。

## 十、英雄纸娃娃和装备

英雄外观应该与战场角色一致。人类、精灵、兽人各自有基础形象，武器和装备会改变纸娃娃表现。

英雄装备建议保持四类核心决策：

1. 武器：决定攻击方式和构筑路线。
2. 战衣：决定生存和外观主体。
3. 护符：偏技能、续航或功能强化。
4. 圣物：偏终局特效和特殊构筑。

未获得的装备和宝石不应该在背包里完整展示给玩家。图鉴可以显示发现过的内容，背包只显示当前拥有的资源。这样既保留收集感，也避免玩家在战斗中被大量未获得道具干扰。

## 十一、推荐首通路线

首通最稳路线：

1. 种族选人类。
2. 武器选战旗长剑或誓约盾锤。
3. 前期用箭塔 + 炮塔 + 冰塔守关键拐角。
4. 第一次遇到隐形怪前补侦测塔。
5. 遇到飞行怪后补狙击塔、雷塔或导弹塔。
6. 中后期选一个主输出核心：光棱塔、要塞炮、导弹塔三选一重点养。
7. 天赋优先拿防线超频、宝石共振、武器精通或金币成长。
8. 英雄不要站桩，漏怪时右键移动补线。

这套路线不是上限最高，但容错最高。熟悉后可以尝试：

- 精灵 + 猎影长弓：金币滚雪球。
- 精灵 + 哨戒弩：远程视野和射程压制。
- 兽人 + 工匠战锤：近战守线和攻速塔阵。
- 人类 + 召唤法杖：神话眷属、召唤联动、持久战。
- 精灵/兽人 + 夜刃匕首：操作型 Boss 爆发。

## 十二、常见失败原因

1. 只堆贵塔，不补控制。
2. 只看伤害，不处理隐形、飞行、自爆、静默。
3. 英雄一直站在原地，没有补线和拉怪。
4. 天赋选择太分散，整局没有核心路线。
5. 宝石平均分配，导致没有一座塔真正成型。
6. 战争迷雾地图缺光源，敌人进入攻击范围时已经太晚。
7. Boss 波前没有准备单体爆发和减速。

## 十三、给玩家的一句话总结

新手先学会“减速 + 范围 + 单体 + 侦测”的基础塔阵；进阶后再围绕“种族 + 武器 + 宝石 + 每波天赋”做构筑。只要每一局都能回答“我的主输出是谁、我的控制在哪里、我怎么处理特殊怪”，这款塔防的肉鸽味道就会真正出来。
