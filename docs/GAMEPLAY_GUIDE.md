# 《保卫萝卜》Bevy 版玩法攻略

当前版本的构筑核心是：五种基础防御塔组成稳定防线，英雄武器自动提供爆发、控制、召唤和塔阵联动。种族决定英雄属性倾向，武器决定技能组合与打法，装备和每波海克斯继续强化选定路线。

## 一、胜利循环

每关的目标是守住萝卜，不让怪物沿路径抵达终点。稳定通关通常遵循四步：

1. 用低价塔覆盖路径拐角和长直线。
2. 用冰塔延长输出时间，用侦测塔处理隐形威胁。
3. 移动英雄补漏、卡线，让职业技能覆盖关键路线。
4. 把升级、装备和海克斯集中给主输出，不要平均分散。

敌人弱点、地图路线、英雄定位和塔阵功能必须互相配合。贵塔和高面板伤害不能替代减速、侦测与站位。

## 二、五种防御塔

防御塔只保留五种。它们负责可预测、可重复的基础防线；更复杂的旧塔机制已经进入英雄职业技能。

| 快捷键 | 防御塔 | 定位 | 适合位置 |
|---|---|---|---|
| `1` | 箭塔 | 低价、高频单体物理输出 | 长直线、补漏区 |
| `2` | 炮塔 | 范围物理爆炸 | 拐角、怪群密集区 |
| `3` | 魔法塔 | 高伤单体秘法输出 | 重甲与高生命目标附近 |
| `4` | 冰塔 | 持续减速 | 主火力区入口 |
| `5` | 侦测塔 | 揭示隐形敌人并补充低额输出 | 入口、关键拐角、迷雾区 |

基础组合是箭塔 + 炮塔 + 冰塔。出现隐形敌人前补侦测塔，重甲或高生命目标增多时补魔法塔。升级优先给覆盖路径最长、实际开火时间最多的塔。

## 三、英雄种族

英雄是可移动战斗单位，不是被动头像。点击英雄后可命令其移动，近战英雄可以卡线，远程英雄应通过走位保持输出距离。

| 种族 | 属性倾向 | 适合打法 |
|---|---|---|
| 人类 | 均衡生命、伤害和攻速 | 首次通关、未知地图 |
| 精灵 | 高射程、高攻速、高移速，生命较低 | 远程武器、游走补线 |
| 兽人 | 高生命、高伤害，射程和机动较低 | 近战卡线、正面抗压 |

种族与武器相互独立。玩家选择的是本局打法，不是固定职业。

## 四、九种职业与自动技能

每种武器拥有三招符合职业特色的完整技能：前两招从开局即可自动施放，第三招在30级解锁。每招分别经历蓄力、释放与收招，有独立冷却，不需要手动施放按钮。技能点只强化所投技能的伤害、控制、范围、数量或召唤物，不提高英雄基础属性。

| 武器 | 技能一 | 技能二 | 30级终极 |
|---|---|---|---|
| 战旗长剑 | 破阵冲锋：冲锋、击退、震晕 | 旋锋横扫：近身弧形剑斩 | 裂地连斩：连续震地 |
| 星火法杖 | 星火长径：贯穿火径与持续燃烧 | 寒星禁锢：敌群脚下的冰牢 | 群星坠落：多颗陨星轰击 |
| 猎影长弓 | 淬毒齐射：多目标毒箭 | 穿云狙击：高穿甲直线贯穿箭 | 万箭风暴：多轮箭雨 |
| 誓约盾锤 | 盾击震退：正面盾击与震晕 | 圣光修复：治疗受损友军与萝卜 | 圣域庇护：持续治疗与驱敌 |
| 雷暴法器 | 雷链审判：逐目标连锁闪电 | 风眼涡流：牵引、禁锢敌群 | 雷霆风暴：多轮麻痹落雷 |
| 哨戒弩 | 棱光折射：通过塔阵折射哨箭 | 缚影哨箭：冻结与破甲诅咒 | 永恒哨域：部署三处射击阵位 |
| 夜刃匕首 | 暗影伏击：首领优先绕后突刺 | 毒刃散射：扇形淬毒飞刀 | 绝命刺杀：单体残血处决 |
| 召唤法杖 | 神话契约：召唤移动眷属 | 亡魂召回：消耗已败敌人亡魂召回友军 | 旧日眷属：召唤远古眷属与护卫 |
| 工匠战锤 | 守卫组装：组装防区巡逻近战守卫 | 追踪火箭：追踪、爆炸与燃烧 | 守卫工坊：重装守卫与修复场 |

技能要点：

- 每招冷却独立，具体秒数见技能提示；装备和海克斯可以缩短冷却，最低8秒。暂停、休整和阵亡时不推进冷却或施法。
- 破阵冲锋和暗影伏击会改变英雄位置，玩家移动时等待或取消未释放的位移施法。
- 星火长径覆盖英雄与目标之间的线段，沿路径站位更容易命中敌群。
- 雷链审判需要目标之间距离足够近，分散敌群会提前断链。
- 棱光折射利用附近防御塔作为锚点，靠近塔阵更容易覆盖不同方向。
- 需要目标的技能就绪但没有有效对象时安静等待，不消耗冷却。
- 召唤法杖三招都召出真实作战单位，不使用直接范围伤害或属性加成代替召唤。
- 开波后神话契约和已解锁的旧日眷属在有召唤空位时自动施放，不必等敌人接近。亡魂召回有可用亡魂和空位即可施放，同样不要求附近有敌人。
- 亡魂召回只消耗本局已击败非首领的亡魂，不复制仍存活的敌人。
- 眷属、亡魂、机械守卫和装备友军共享每名英雄12个存活单位上限；只为实际召回的友军消耗亡魂。
- 单只移动召唤物也在英雄身旁独立待命；波间准备期间暂停召唤物寿命，与技能冷却保持一致。

## 五、英雄操作

英雄主要承担四个职责：补漏、卡线、拉扯和联动。长线地图让英雄在薄弱路段巡逻；短线地图让英雄靠近萝卜或关键拐角。自爆怪和首领技能出现时，不要让英雄与核心塔挤在同一受击区。

英雄开局免费自动登场，阵亡后经过两波自动重生，不提供立即重生按钮。

## 六、升级、修理与目标优先级

选中防御塔后可以升级、修理、切换目标优先级、装备遗物或出售。塔会受到攻城怪、远射怪和首领技能伤害，因此修理不是装饰功能。

- 最近：维持普通防线。
- 前锋：防止漏怪。
- 强者：集中精英和坦克。
- 残血：加快收割和连杀。
- 威胁：优先首领、MOSS 与攻城单位。

按 `Tab` 可选中受损最严重的塔，适合紧急修理。

## 七、装备与海克斯

防御塔遗物提供伤害、射程、攻速、护甲、范围和元素等强化。装备提示只围绕五种当前防御塔推荐，不再对应已移除的塔型。

英雄装备独立于塔遗物，按武器适配提供技能倍率、冷却缩减、生存、移动、光环或召唤强化。四件同套装备随第一个技能释放自动触发联动。

每波三选一海克斯分为种族、武器和公共路线。纯属性成长在这里选择：武器节奏提供攻速、移速和技能冷却缩减；武器精通提高伤害与技能威力。前期缺钱时优先经济，开始漏怪时补攻速、射程或英雄伤害。形成主路线后继续集中，不要为了稀有度改走无关方向。

## 八、敌人克制速查

| 敌人类型 | 处理方法 |
|---|---|
| 快速怪 | 冰塔减速，雷暴法器控群 |
| 坦克 / 重甲 | 魔法塔、穿甲遗物、穿云狙击或绝命刺杀 |
| 飞行怪 | 箭塔、魔法塔与远程英雄集中输出 |
| 隐形怪 | 侦测塔或哨戒弩提前覆盖 |
| 护盾怪 | 高频攻击破盾后集中爆发 |
| 再生 / 治疗怪 | 前锋或威胁优先，避免战线被拖长 |
| 分裂 / 集群怪 | 炮塔、星火长径、雷链审判、追踪火箭 |
| 冲锋怪 | 冰塔提前减速，战旗长剑击退 |
| 攻城 / 远射怪 | 威胁优先，英雄补位并及时修塔 |
| 自爆怪 | 在远处减速并集火，避免靠近英雄和核心塔 |
| 首领 | 单体输出、减速、破甲和职业技能协同覆盖 |

## 九、迷雾、光照与地图

战争迷雾让视野成为建塔决策。入口、拐角和主火力区应有固定光源或侦测覆盖；英雄和技能特效只能临时补充视野。

路径越复杂，炮塔和冰塔越容易获得长时间收益；路径越短，箭塔、魔法塔与英雄爆发越重要。布塔前先看路径覆盖，不要只看离入口或萝卜的直线距离。

## 十一、稳定首通路线

1. 选择人类 + 战旗长剑或誓约盾锤。
2. 用箭塔 + 炮塔 + 冰塔守住覆盖最长的拐角。
3. 第一次出现隐形怪前补侦测塔。
4. 重甲增多时补魔法塔，并升级主输出。
5. 把英雄留在薄弱侧，让技能自动防漏、保塔或处理首领。
6. 装备和海克斯集中到一条主输出路线。

进阶路线可以围绕精灵 + 猎影长弓滚经济、精灵 + 哨戒弩扩大塔阵覆盖、兽人 + 工匠战锤建立正面阵地，或用召唤法杖的神话眷属与幽魂拖住长战线。

一句话总结：先用“单体 + 范围 + 减速 + 侦测”建立五塔防线，再通过英雄站位和职业技能补上冲锋、火场、斩杀、圣垒、雷链、棱光、暗影、召唤和导弹九种战术身份。
